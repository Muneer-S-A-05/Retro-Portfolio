# Retro-Portfolio

An honest, zero-AI attempt to build a portfolio website completely from scratch. 

## The Context
Yes, I am entering my placement period very soon. Yes, conventional wisdom says I should use AI shortcuts, templates, or page builders to rush a portfolio out the door. 

Instead, I’m doing this the hard way.

## Why Scratch? Why No AI?
* **True Mastery:** I want to actually understand every line of code in my repository, not just copy-paste what a language model suggests.
* **Stand Out:** In an era of identical, AI-generated portfolios, this is a testament to my personal grit, curiosity, and foundational coding skills.
* **The Goal:** To have a fully functional, uniquely "me" portfolio built from the ground up before the end of 2026.

People might call it inefficient; I call it learning.
